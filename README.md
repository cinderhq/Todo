
# To-Do List

A simple to-do list project built to practise JavaScript and DOM manipulation.

## About

This project explores how JavaScript can be used to manage tasks and update a webpage dynamically.

## What I Learned

- Selecting and manipulating DOM elements
- Handling input and button events
- Working with arrays and objects
- Rendering task information dynamically
- Practising basic application logic

## Technologies

- HTML
- CSS
- JavaScript

## Getting Started

1. Open the project folder in your code editor.
2. Open the main HTML file in your browser, if no local server is required.
3. Follow any additional setup instructions required by the project.
